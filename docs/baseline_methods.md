# 三个学习基线怎样实现与现实部署

迁移现实本身不是新的方法贡献。Hora与AnyRotate已有真机证据；
Sharpa参考仓库提供SharpaWave训练和部署流程。本项目仍必须证明
伯牙手上的持续旋转与部署，但不能因首次移植成功就声称超越原论文。

|工作|训练机制|真机策略输入与迁移|伯牙适配缺口|
|---|---|---|---|
|Hora，CoRL2022|PPO联合训练物体属性编码器和策略；质量、摩擦、质心、尺寸等随机化；封顶角速奖励及姿态/线速/力矩/功惩罚让换指出现|冻结基础策略，30帧关节与动作历史估计8维extrinsics，监督目标来自教师编码；20Hz目标位置、300Hz低层PD；无需物体真值或触觉|16个Allegro直接驱动关节须改成13个伯牙实际输入；历史必须反映实际电机/被动耦合和延迟，而不是把仿真关节当可测量电机|
|AnyRotate，CoRL2024|特权PPO教师追踪到达后更新的小目标姿态；接触与稳定性奖励随进展课程；本体/触觉历史TCN学生以隐变量MSE和动作分布NLL蒸馏|真实接触实验收集图像、姿态和力标签，CNN提取接触极角/方位角与力幅值，SSIM判接触；与仿真特征、滤波和量程对齐；学生不读物体目标真值|伯牙已有点力阵列与三维合力，可标定接触位置/分布；仿真先用接触特征，实际有效点与几何/量纲须核对，不能把未标定点阵或低维力PPO冒称完整AnyRotate|
|Sharpa参考实现|PPO＋特权属性编码＋30帧TCN本体适应，代码有Hora继承；Isaac Lab，摩擦/质量/质心随机化，重力课程从小重力增到约10m/s²|关节/动作历史与触觉力；SharpaWave SDK、触觉零点校准和主机/板载部署路径|22DoF与伯牙16输入、腱耦合、马达接口不同；当前复制的是用户fork部分源码，不是验证过的原法伯牙成绩|

依据：Hora原文第3节、第4节和附录奖励/网络；AnyRotate原文第3.1—3.3节及附录A/B/G/H；Sharpa的`models.py`、适应训练、`sharpa_wave_env_cfg.py`、部署代码与README。原文与文件身份见`../references/source_manifest.json`。

PPO、域随机化、历史隐变量适应和教师学生蒸馏的组合已有先例。
当前teacher-v2的奖励归一化是针对已观测失败的训练修正，尚非原创算法
或迁移能力证明。候选研究问题是：实际腱耦合/回差/时延及接触变化
是否导致现有历史适应失效，是否需要新的可观测表示或适应机制。
这是待验证假设；先获得能工作的对齐基线，再用相同伯牙条件下的
对比、消融和真机误差实验决定贡献。更换机器人或调用不同引擎本身
也不保证方法创新，暂不承诺SOTA或刊物等级。
