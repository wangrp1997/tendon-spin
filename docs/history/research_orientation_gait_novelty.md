**核查日期：** 2026-10-01  
**范围：** 候选主线——用手朝向使四指准静态抬起可行；离线用「实测载荷可行性证书」（LP，抬一指时其余指在保守摩擦棱锥内平衡当前外载，不需质量）筛选朝向/抓取；在线用触觉力重算证书门控简单换指步态；对比采样 MPC 的模型依赖。

## 0. 结论（先看）

1. **「重力 / 手朝向影响无支撑在手操作难度」已被明确写出并实验量化，但不是你们的发明。** AnyRotate（全文）直接写：掌心非朝上时更难在重力下保持并操作；六种手朝向真机表显示 palm up/down 优于 thumb up/down（p.1–2, p.7 Table 2）。Hora（全文）固定指尖、绕手系 z 轴转，物体须在掌心上方约 14.5 cm，属掌面在下的重力几何，**不**分析换朝向使「每指可零载抬起」（p.1, p.14）。  
2. **「用手朝向选择，使准静态换指（每指可安全卸载）由不可行变为可行，并用无质量实测载荷 LP 证书做离线构型筛选 + 在线门控」——在已核全文中未见同构先例。** 最近邻分别覆盖：朝向难度（AnyRotate，解法是 RL 重力不变策略）；证书式力分配/换指（Jia，模型质量+桌面枢轴，无朝向筛选、无卸载前实测证书）；质量阈值/启发式力事件（Ma、Fan 质量阈值）；wrench closure 序列（Platt）；外在灵巧性用环境/重力（Dafle，**仅摘要**）。  
3. **不能当创新点的说法：**「换指 / 抓取步态」「力封闭/摩擦锥可行性」「力传感触发换指」「无学习在手旋转」「重力有影响」「比 MPC 更鲁棒」等单独表述。  
4. **建议贡献表述：** 在绳驱四指、无支撑圆柱持续旋转设定下，**(a)** 用零载抬起静力证书量化手朝向对「能否准静态换指」的分界；**(b)** 离线证书选朝向与抓取，在线触觉重算证书门控换指顺序/夹持力/跳过重试；**(c)** 相对依赖精确接触模型的采样 MPC，在摩擦/质量/接触刚度失配下更稳健（须用消融证明）。  
5. **必加基线：** 原朝向 vs 证书筛选朝向；证书门控开/关；Ma 式力阈值；Jia 式模型参考力定时卸载；固定开环步态；采样 MPC（标定模型 vs 失配）。最大表述威胁：**AnyRotate（朝向）** + **Jia/Ma（力/换指）**。

## 2. 手朝向 / 重力 / 外在灵巧性 / 经典步态

### 2.1 Hora — Qi et al., arXiv:2210.04887v1（全文）

- **做什么：** 仿真 RL + 快速运动适应；Allegro 仅指尖、多物体绕手系 **z 轴**持续转；部署用本体历史估 extrinsics（p.1–2, p.4）。  
- **朝向/重力：** 任务明确不能靠掌面支撑防落（p.1）；终止条件含物体须高于掌心中心约 **14.5 cm**（p.14）——几何上是**掌在物体下方**的指尖抓持。奖励旋转轴取世界系 \(+\hat z\)（附录 p.14）。**未**系统比较多种腕朝向，也**未**用静力抬指证书选朝向。  
- **与我们：** 同属无支撑指尖旋转；对方用学习适应，固定重力几何；我们主张**改朝向**打开准静态换指，无学习证书门控。

### 2.2 AnyRotate — Yang et al., arXiv:2405.07391v3（全文）

- **做什么：** 稠密触觉 sim-to-real RL；**任意轴 + 任意手朝向相对重力**的统一策略；六种关键朝向：palm up/down、thumb up/down、base up/down（Fig.1 **p.1**）。  
- **朝向论述（关键）：**  
  - 「…requires high-precision control of secure grasps in the presence of gravity (i.e. gravity invariant): **it is harder to hold an object while manipulating it if the palm is not facing upwards**」（**p.2**）。  
  - 随机初始化手朝向训练；先前工作多只做单一朝向（含朝下）（**p.3**）。  
  - 真机：固定朝向训的策略在任意朝向差；dense touch 最好；**「Hand orientations. The performance dropped as the hand directions changed from palm up and palm down, … to the thumb up and thumb down」**；后者重力载荷与驱动方向更不利（**p.7**, Table 2）。  
- **与我们：** **已明确「朝向相对重力改变操作难度」并量化。** 解法是 **RL 重力不变策略**，不是「选一个朝向让准静态四指卸载全部可行」；也不做离线 LP 证书构型筛选。我们若主张 (1)，必须写成：**在准静态换指 / 证书可行域意义下**朝向是决定性设计变量，并以证书余量分界实验区分于 AnyRotate 的「难度随朝向变、但用策略硬扛」。

### 2.3 外在灵巧性 — Chavan-Dafle et al., ICRA 2014（**仅摘要**，本轮 DSpace/作者 PDF 未取得正文）

- OpenAlex 摘要要点：用环境外力（推挤桌面/墙等）做 in-hand 重抓，对比指尖内在灵巧。  
- **与我们：** 同属「重力/环境力可被利用」；对方改的是**与环境接触模式**，不是腕朝向下的纯指尖准静态抬指证书。引用时标仅摘要，勿写页码细节。

### 2.4 经典抓取步态（多数本轮仅摘要或经二次文献）

| 工作 | 证据 | 要点 | 与我们 |
|------|------|------|--------|
| Leveroni & Salisbury 1996 grasp gaits | 仅摘要/经 Sundaralingam 引用 | 「grasp gaits」重定向 | 步态概念先例；未见朝向证书筛选 |
| Rus 1999 等协调操作 | 仅摘要检索 | 指重置操作 | 同左 |
| Hong / Lafferriere / Mishra / Tan 1990 | 本轮未取得全文 | 经典 finger gait 理论 | 仅可作历史引用 |

| Platt / Fagg / Grupen 2004 | **全文已在** `research_jia2023_overlap.md` 核验（扫描版） | 在 wrench closure 下切换抓取控制器序列 | **概念先例**：换指保持封闭；非朝向筛选、非实测载荷无质量 LP |

## 3. 静力可行性 / 抓取质量余量 / 力传感门控换指

> Jia / Ma / Morgan / Platt 的重叠细节以 `research_jia2023_overlap.md` 为准；此处只抽与**朝向主线**相关的边界。

### 3.1 Fan et al., arXiv:1710.10350v1（全文）—*Real-Time Robust Finger Gaits Planning…*

- 双层：抓取质量（物体质量指标+手可操作度）低于阈值则规划换指；鲁棒控制+接触力优化抗质量/惯量不确定（p.1–2）。  
- 换指用 1D 触觉看法向力，做 velocity-force 控制（p.3）；重力进入对象动力学框图（p.4）。  
- **与我们：** 有「质量指标触发换指」；**不是**「实测外载、不需质量、抬指零载可行性证书」；**不**用手朝向打开四指可抬起集合。

### 3.2 Jia 2023（全文，作者 PDF；页码见 overlap 文档）

- 桌面枢轴 + 模型质量/惯量力优化 + 渐变卸载；**卸载前无在线可行性证书**；接触序列给定。  
- **与我们：** 力分配/三段换指不能再称创新；**朝向筛选、无支撑自由圆柱、实测载荷无质量证书门控**仍可区分（overlap §0）。

### 3.3 Ma 2024（全文，overlap）

- 手心朝下捏纸杯；力事件切换固定原语；约 240°；启发式阈值。  
- **与我们：** 粗表述「力触发换指转圆柱」被占；须靠证书定量、朝向分界、多圈与绳驱设定区分。旋转轴与重力关系据图判读为竖直（overlap）。

### 3.4 Morgan et al., arXiv:2201.07928（全文，overlap；本轮未重读页码）

- 无学习、无支撑换指，靠视觉闭环；非触觉证书。限制「首个无学习无支撑换指」表述。

### 3.5 其他近作

- Hang 2016 Hierarchical Fingertip Space：**仅摘要**（overlap）——力不够再换指。  
- 学习派（AnyRotate、Hora 等）：占「无支撑指尖旋转」本身，不占可解释证书+朝向筛选。

**「证书离线选构型 + 在线门控」：**  
- 部件先例：Platt（封闭约束序列）、Fan（质量阈值触发）、Jia（离线优化力）、Ma（在线力事件）。  
- **未见**「同一无质量实测载荷抬指 LP：离线搜腕朝向/抓取 → 在线同式门控换指」的完整先例（在已核全文范围内）。

## 5. 结论细答

### 5.1 「手朝向决定准静态换指可行性」是否已被明确提出？

- **「朝向相对重力改变在手操作难度」：是，AnyRotate 明文 + 真机分朝向表（p.2, p.7）。**  
- **「在准静态、零载抬起、摩擦棱锥证书意义下，朝向是可行性开关（原朝向拇指不可抬 → 侧立下俯后四指可抬）」：已核全文中未见同构主张与分析。**  
- 写作时勿写「首次发现重力影响」；应写「首次（或首次在绳驱无支撑换指设定下）用抬指静力证书刻画并利用该分界」。

### 5.2 「证书离线选构型 + 在线门控」有无先例？

- **部分先例、无完整同构：** 质量/封闭/启发式触发换指已有；**用同一不需质量的实测载荷抬指 LP 同时做腕朝向离线筛选与在线换指门控**——未见直接先例。  
- 与 Jia overlap 文档一致：在线实测证书+调度仍是可辩护增量，但须消融。

### 5.3 哪些说法不能算创新？

- 换指 / grasp gait / 保持 wrench closure（经典+Platt）  
- 摩擦锥力分配、渐变卸载加载（Jia）  
- 力阈值/事件驱动换指（Ma、Hang 摘要级）  
- 「重力下无支撑更难」「掌心朝上更容易」（AnyRotate）  
- 「无学习在手旋转」（Morgan、Ma、模型式工作）  
- 「比 MPC 稳健」若无失配消融则只是口号  

### 5.4 应如何表述贡献？必须加哪些基线？

**推荐主贡献句：**

> 在绳驱四指无支撑圆柱旋转中，用「单指零载卸载」的实测载荷静力证书表明：手相对重力的朝向决定准静态换指是否可行；据此离线筛选朝向与抓取，并在执行中用触觉力重算同一证书门控换指，从而在不依赖精确接触模型 rollout 的条件下实现持续旋转。

**必加基线 / 消融：**

1. **朝向：** 原始朝向 vs 证书筛选朝向（同一步态/控制器）。  
2. **门控：** 证书开 vs 关（固定顺序强制换指）。  
3. **Ma 式：** 力幅值/阈值事件，无平衡 LP。  
4. **Jia 式：** 名义质量+μ 的模型参考力定时卸载（可藏配重/降μ）。  
5. **开环固定步态。**  
6. **采样 MPC：** 接触/摩擦/质量/刚度标定正确 vs 故意失配——支撑主张 (3)。  
7. **报告：** 证书误拒/漏判、四指最小余量、多圈成功率、掉落率。

## 7. 一句话

**AnyRotate 已写明「朝向相对重力改变难度」；你们的可辩护点是把该事实收成「准静态抬指证书可行域」的设计开关，并用同一证书做离线构型选择与在线换指门控，而不是再宣称「发现重力重要」或「首次力反馈换指」。**
