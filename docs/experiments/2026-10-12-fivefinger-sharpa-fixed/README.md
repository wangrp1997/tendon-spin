# 固定48×60毫米圆柱：五指抓取规划

用户同意按Sharpa README推荐尺寸，重新调整物体朝向、位置及五指构型。
本次保持直径48、高度60毫米、50克，执行[预声明协议](PROTOCOL.md)的两组
确定性有界求解。原物体、抓取44、28状态缓存和全部权重保留，没有新训练。

第一组找到五个指腹均接近物体的几何构型，但静力摩擦条件未通过；第二组
几何及静力条件均未通过。因此没有启动依赖的Isaac持握验证，也没有生成
可用于训练的五指缓存。五个表面接近物体不代表已经抓稳。

摩擦锥超额指规划切向力超过`.4 × 法向力`，这里是优化所得的力，**不是测得
的接触力**。第一组最大超额来自LF，FF也有约.02449牛顿超额；不能用合力
平衡或距离接近来替代摩擦条件。它有三对跨指CAD距离返回0，未达到规划的
.3毫米正间隙目标：mfbase/rfproximal、mfmiddle/lfmiddle、rfdistal/lfmiddle。
这些返回值没有给出正分离裕度，不作为已验证的无自碰证明。

每组least-squares实际38/43次nfev，随后SLSQP均达到200次迭代上限；两组
总墙钟约30秒。仅使用现有MuJoCo3.11.0正运动学及几何查询，积分0步，Isaac
执行0次、训练0动作。没有实际持握轨迹，所以净转角/峰值/倒转/持握时长均
不适用；实际停止原因是固定CPU求解预算结束且无完整合格候选。

原四指朝向下的失败记录见[前一阶段](../2026-10-12-fivefinger-grasp/README.md)。

求解复用原botyard-inhand的CAD曲面、接触坐标及静力约束，显式扩展到五指；
用凸包半空间射线构建同类指腹样条，距离查询前更新BVH。局部求解失败不能
证明48×60毫米无法五指抓取，也不能证明换尺寸无效。后续建议先固定尺寸，
解决抓取求解的摩擦分配和跨指间隙；不以训练或改接触判据绕过失败。
进一步求解/物理试验等待用户选择，不自动续跑或参数扫描。
